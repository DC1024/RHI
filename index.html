安装步骤

先退出正在运行的 RHI。已装官方版的话直接覆盖安装目录即可，设置和模组都会保留。

下载 zip 包

取 RHI-zh-CN-v2.8.5-zh-cn-11-win-x64.zip（约 35 MB）。

整目录解压

解压到任意目录，然后运行其中的 RHI.exe。

已装官方版 → 覆盖

把解压出来的全部文件覆盖进安装目录（默认 C:\Program Files\RHI）， 管理员权限点「继续」即可。游戏列表、已装模组、设置全部保留。

切换中文

启动 → Settings → Language → 简体中文，即时生效。

⚠️ 不要只拷贝 exe

WinAppSDK 的运行时组件必须以真实文件形式放在 exe 旁边，否则启动会报 0x80040111 ClassFactory 并直接退出。官方那个约 100 MB 的单文件 exe 是把 RHI.dll 和 resources.pri 打包进去的， 同理无法这样单独替换。

ℹ️ 关于自动更新

本中文分支已主动关闭程序内自更新。原因有两个：上游安装器是英文版， 「立即更新」会把中文版覆盖回英文；且本分支发布的是免安装 zip，内置更新器也无法正确应用。 要升级请到 Releases 页面 手动下载新的 v*-zh-cn-* 包覆盖即可。

运行环境与校验

本版本为 framework-dependent，需要系统已安装 .NET 8 桌面运行时（能正常跑官方版即可满足）。

常见问题

关于分支关系、覆盖安装和已知遗留项。

这是官方版本吗？和上游什么关系？

不是官方版本，本仓库是 RankFTW/RHI 的非官方分支。唯一功能性改动是新增简体中文界面，其余代码与上游保持同步。

翻译词条源自社区 PR #20（原作者 HexBen123）， 由本分支 rebase 到当前主线。遵循上游 GPL-3.0 许可，源码与所有修改均开放。

官方暂未提供中文支持。需要原版请到上游下载。

覆盖安装后我的设置和模组会丢吗？

不会。覆盖的是程序文件本身，游戏库、已安装的模组记录、各项设置都保存在用户数据目录里， 覆盖后照常读取。详细步骤见包内的 README-patch.md。

为什么关掉了自动更新？

两个原因：上游的更新安装器是官方英文版，点「立即更新」会把中文版覆盖回英文； 且本分支发布形态是免安装 zip，内置更新器依赖安装器流程，无法正确应用覆盖。

升级请到 Releases 页面手动下载新的 v*-zh-cn-* 包覆盖。

还有哪些地方没翻译？

主界面、设置面板、全部对话框与提示（含新增的「捐赠 / 模组作者」面板）均已汉化，详见仓库内 ZH-CN-BUILD.md。

怎么参与或反馈？

直接开 issue 或 PR：github.com/DC1024/RHI。 翻译改动集中在 RenoDXCommander/Services/LocalizationService.cs 的 SimplifiedChinese 字典，补充词条后跑一遍全口径扫描确认 0 缺失即可。
